# Навантажувальний тест

Імітує N гравців онлайн проти локального сервера: кожен тримає WebSocket (як на головній), частина
грає з ботом (HTTP), пари грають між собою (WebSocket), решта дивиться чужі партії.

```bash
# 1. Тестова база: 600 гравців з ботом, 150 пар, 100 глядачів (усього 1000).
npx tsx scripts/load/seed.ts /tmp/load.db 600 150 100 /tmp/users.json

# 2. Сервер на цій базі (в окремому терміналі).
PORT=8099 DB_FILE=/tmp/load.db npm run server

# 3. Навантаження на 180 с; гравці думають над ходом 8–20 с.
THINK_MIN=8000 THINK_MAX=20000 node scripts/load/run.mjs /tmp/users.json 180
```

Кожні 15 с друкується: скільки ходів зроблено, затримка ходу з ботом і ходу через WebSocket
(p50/p95), кількість помилок. Процесор і пам'ять сервера — `top` або Activity Monitor.

Результати на 4 ядрах (3 потоки бота), 1000 онлайн — у [docs/networking.md](../../docs/networking.md#масштаб).
