# Ultrachess

Онлайн-шахи 1 на 1, де кожна фігура — картка з модифікованим ходом. Це скелет сайту за [ТЗ](docs/spec.md):
каталог карток, конструктор колоди та матч проти бота.

## Запуск

```bash
npm install
npm run dev        # локальний сервер розробки (Vite)
npm run build      # перевірка типів + збірка в dist/
npm run preview    # перегляд зібраного сайту
npm test           # тести рушія правил і бота
```

Зібраний сайт у `dist/` статичний: його можна викласти на будь-який статичний хостинг.
Серверна частина не потрібна, бо партія проти бота рахується в браузері.

## Що є на сайті

- **Колекція** (`#/cards`) — усі 69 карток із фільтрами за фігурою та рідкістю.
- **Колода** (`#/deck`) — конструктор на 16 позицій із валідацією (§2.2 ТЗ). Картки перетягуються з
  колекції на дошку (мишкою або пальцем), або натисніть клітинку, а потім картку. Пішака можна
  кинути одразу на всі 8 клітинок. Кнопка збереження неактивна, поки порушено хоч одне правило, і
  список показує, яке саме. Колоди зберігаються в `localStorage` цього браузера.
- **Матч** (`#/match`) — дошка 8×8 проти бота:
  - підсвітка легальних ходів із урахуванням карток;
  - вибір варіанта ходу, коли на одну клітинку ведуть кілька ходів (перетворення пішака, «взяти й
    повернутись» тощо);
  - кнопки здібностей міфологічних карток з індикатором cooldown;
  - статуси шаху, мату, пату та нічиї;
  - підсумок партії.

## Структура

```
src/engine/            рушій правил без прив'язки до UI
  cards.ts             каталог 69 карток (id, рідкість, текст правил, moveModifierId)
  modifiers/           генератори ходів: картка → generateMoves (§6 ТЗ)
  apply.ts             виконання ходу: взяття, захисні ефекти, автоматичні тригери
  legal.ts, attack.ts  легальність ходів, шах, погляд гравця на позицію
  abilities.ts         кнопки з cooldown
  match.ts             MatchState, історія, нічиї, performAction
  view.ts              що бачить кожен гравець (прихований стан не витікає)
  deck.ts              валідація колоди
  bot/                 оцінка позиції та мінімакс з альфа-бета
src/ui/                React-інтерфейс; бот працює у Web Worker
docs/spec.md           ТЗ
docs/engine-decisions.md  як рушій трактує неоднозначні місця правил
```

Реалізовано всі 69 карток, тож fallback-заглушок немає. Там, де ТЗ допускає кілька прочитань,
рушій обирає одне з них; усі такі рішення зібрано в [docs/engine-decisions.md](docs/engine-decisions.md).
