# Ultrachess — ТЗ на скелет сайту

Онлайн-шахи 1 на 1, де кожна фігура — картка з модифікованим ходом (стиль Clash Royale). Колекція вимкнена з обсягу цього ТЗ: тут потрібен робочий скелет із трьома модулями — картки, конструктор колоди, матч проти бота.

## 1. Обсяг (scope)

**Входить у цей скелет:**
- Каталог усіх 69 карток з правилами.
- Конструктор колоди з валідацією обмежень.
- Матч проти простого бота на дошці 8×8.
- Рушій правил, що вміє рахувати ходи з урахуванням модифікацій карток.

**Не входить (окремі ТЗ пізніше):**
- Система випадіння карток зі скринь та економіка (вже описана окремим промптом для БД).
- Мультиплеєр (PvP по мережі).
- Акаунти, авторизація, збереження прогресу між сесіями.

## 2. Модулі сайту

### 2.1 Колекція карток
Сторінка-каталог усіх 69 карток. Фільтри: фігура (пішак/слон/тура/кінь/ферзь/король), рідкість. Кожна картка: назва, фігура, рідкість, текст правил. У цьому скелеті вважати, що у гравця відкриті всі картки (систему розблокування додамо пізніше).

### 2.2 Конструктор колоди
Гравець збирає колоду з 16 позицій:

| Фігура | Позицій на дошці | Скільки версій обирає гравець |
| --- | --- | --- |
| Пішак | 8 | 1 або 2 різні + формація |
| Тура | 2 (№1, №2) | кожна окремо, 1 версія на позицію |
| Слон | 2 (№1, №2) | кожна окремо, 1 версія на позицію |
| Кінь | 2 (№1, №2) | кожна окремо, 1 версія на позицію |
| Ферзь | 1 | 1 версія |
| Король | 1 | 1 версія |

Правила валідації:
- Для пішаків — рівно 1 або 2 унікальні картки. Якщо 2, гравець задає формацію: рядок з 8 символів (`1`/`2`), зліва направо по вертикалях a–h. Формація за замовчуванням із пресетів: `11112222`, `22221111`, `12121212`, `21212121`.
- Тура №1/№2, Слон №1/№2, Кінь №1/№2 — можуть бути однакові або різні версії, обираються незалежно.
- У всій колоді (рахуючи всі 16 позицій) не більше **1 картки рідкості "міфологічна"**. Якщо гравець уже обрав міфологічну картку на одній позиції, усі інші міфологічні картки в конструкторі стають недоступними для вибору.
- Пішаки міфологічних версій не мають (у каталозі їх немає).
- Кнопка "Зберегти колоду" активна тільки якщо всі перевірки пройдені; інакше показати, яка саме умова порушена.

### 2.3 Матч проти бота
- Дошка 8×8, гравець проти бота, обидва зі своїми колодами (бот бере дефолтну колоду з класичних версій усіх фігур, якщо для нього окрему колоду не налаштовано).
- Хід гравця: клік на фігуру → підсвітка легальних ходів, рахованих рушієм з урахуванням карток → клік на цільову клітинку.
- Кнопки активних здібностей (тільки для міфологічних карток) показуються окремо від дошки, з індикатором cooldown.
- Статус партії: чий хід, шах, мат, пат, нічия.
- Після завершення партії — просте резюме (хто переміг, кількість ходів).

## 3. Модель даних

```
Card {
  id: string
  name: string
  pieceType: pawn | bishop | rook | knight | queen | king
  rarity: common | rare | epic | legendary | mythological
  rulesText: string
  moveModifierId: string   // ключ до функції-генератора ходів у рушії
}

Deck {
  id: string
  pawnVersions: [cardId] (1 або 2)
  pawnFormation: string (8 символів "1"/"2", лише якщо pawnVersions.length == 2)
  rook1: cardId, rook2: cardId
  bishop1: cardId, bishop2: cardId
  knight1: cardId, knight2: cardId
  queen: cardId
  king: cardId
}

MatchState {
  board: Piece[8][8]
  turn: white | black
  history: Move[]
  cooldowns: { pieceInstanceId: number }  // ходів до готовності кнопки
  onceUsed: { pieceInstanceId: boolean }  // чи вжито здібність "раз за гру"
  hiddenState: {                          // бачить лише власник
    illusions: [...],
    immortalArmed: boolean                // для Безсмертної ферзя
  }
  status: playing | check | checkmate | stalemate | draw
}
```

## 4. Загальні правила рушія

1. Стандартні шахові правила лежать в основі: хід по черзі, шах, мат, пат, рокіровка для будь-якої тури, що ще не ходила. Взяття на проході не використовується (пішакові версії його не мають).
2. Після будь-якого ходу, включно з ходами з карток, власний король гравця не може лишитись під шахом — така дія нелегальна.
3. Ефекти карток діляться на типи, кожен зі своєю логікою в рушії:
   - **Постійні** — завжди активні, змінюють генерацію ходів фігури.
   - **Раз за гру** — прапорець на конкретному екземплярі фігури, після використання назавжди недоступний.
   - **Кнопка з cooldown** — лише в міфологічних карток. Лічильник ходів власника; натискання не витрачає хід; після використання лічильник скидається до заданого числа.
   - **Автоматичні** — спрацьовують без вибору гравця при виконанні умови (Барикада, Засідник, Мученик, Смертник тощо).
4. Пропуск ходу: якщо ефект каже "пропускає наступний хід", ця конкретна фігура не може ходити чи бити на наступному ході власника; власник ходить іншою фігурою.
5. **Прихована інформація** (ілюзії, натиснута кнопка Безсмертної): зберігається окремо в `hiddenState` по власнику. Гравцеві показується власний прихований стан, боту — його власний; чужий прихований стан рушій ніколи не віддає клієнту суперника.
6. Ілюзія: не рухається, не б'є, не дає шаху; блокує шлях суперника як справжня фігура; при спробі суперника стати на неї — зникає, хід суперника витрачений на це; свої фігури проходять крізь ілюзію вільно; зникає через 3 ходи суперника або коли справжня фігура ходить знову.

## 5. Повний каталог карток (69)

Легенда рідкостей: Зв = звичайна, Рд = рідкісна, Еп = епічна, Лг = легендарна, Мф = міфологічна.

### 5.1 Пішаки (14 карток, 4/4/4/2/0)

**Звичайні**
1. **Класичний пішак** — стандартний хід шахового пішака.
2. **Штурмовик** — б'є тільки прямо вперед, не б'є по діагоналі.
3. **Відступник** — може ходити на 1 клітинку назад; немає стартового ходу на 2 клітинки.
4. **Косий пішак** — раз за гру ходить по діагоналі на вільну клітинку; після цього пропускає наступний хід.

**Рідкісні**
5. **Таран** — раз за гру штовхає ворожого пішака прямо перед собою на 1 клітинку назад і займає його місце; не працює, якщо клітинка позаду ворога зайнята.
6. **Діагональний** — ходить по діагоналі вперед на 1 клітинку, б'є прямо вперед; подвійного стартового ходу немає.
7. **Спринтер** — раз за гру проходить 2 клітинки вперед із будь-якої позиції; стандартного подвійного першого ходу немає.
8. **Впертий** — раз за гру міняється місцями з ворожою фігурою прямо перед собою; після цього пропускає наступний хід.

**Епічні**
9. **Марафонець** — першим ходом може пройти одразу 3 клітинки вперед, якщо шлях вільний; без дебафу.
10. **Фантом** — раз за гру перестрибує через одну фігуру прямо вперед на вільну клітинку за нею; після цього не перетворюється на іншу фігуру на останньому ряду.
11. **Списник** — б'є фігуру через одну клітинку прямо перед собою, сам переходить на першу клітинку; по діагоналі не б'є.
12. **Засідник** — якщо ворожа фігура стає по діагоналі перед ним, автоматично забирає її, але гине сам.

**Легендарні**
13. **Щитоносець** — раз за гру, якщо його б'є саме пішак, не гине, а відступає на 1 клітинку назад, якщо вона вільна; від усіх інших фігур гине як звичайно.
14. **Дуеліст** — після взяття фігури може одразу повернутись на клітинку, з якої атакував; якщо повернувся — пропускає наступний хід.

### 5.2 Слони (15 карток, 4/4/4/2/1)

**Звичайні**
1. **Класичний слон** — стандартний хід шахового слона.
2. **Вартовий** — ходить і б'є на 1 клітинку по вертикалі/горизонталі, по діагоналі максимум на 4 клітинки.
3. **Снайпер** — не може бити впритул по діагоналі, ціль мінімум за 2 клітинки; після далекого взяття може пройти ще 1 клітинку далі по тій самій діагоналі, якщо вона вільна.
4. **Десантник** — першим ходом перестрибує одну фігуру на своїй діагоналі, стаючи одразу за нею; після цього пропускає наступний хід.

**Рідкісні**
5. **Стрибун** — постійно перестрибує через одну фігуру на своїй діагоналі, стаючи на першу вільну клітинку за нею.
6. **Мученик** — якщо його з'їдають, фігура-переможець не може ходити наступні 2 свої ходи.
7. **Рикошетник** — доходячи по діагоналі до краю дошки, може відрикошетити ще на 1 клітинку по новій діагоналі.
8. **Ілюзіоніст** — після ходу лишає прихована копію на стартовій клітинці (див. §4.6).

**Епічні**
9. **Проколювач** — атакує ворожу фігуру через рівно одну іншу фігуру на своїй діагоналі; після атаки гине сам.
10. **Ланцюговий** — рухаючись в одному діагональному напрямку не більше ніж на 3 клітинки, може раз змінити напрямок і пройти до 2 клітинок після повороту.
11. **Хамелеон** — замість ходу переходить на будь-яку сусідню вільну клітинку іншого кольору; далі працює як звичайний слон уже на новому кольорі.
12. **Фланговик** — на фланзі/краю дошки може стрибнути вздовж краю на найближчу клітинку свого кольору (через одну клітинку).

**Легендарні**
13. **Левітаційний слон** — cooldown 5 своїх ходів (без ліміту "раз за гру"). З краю дошки може вийти на платформу за межами дошки; платформа існує 3 ходи суперника, слона там можна атакувати; якщо не повернувся до зникнення — гине.
14. **Портальний слон** — раз за гру виходить за край дошки й з'являється з дзеркально протилежного боку, продовжуючи хід; може одразу взяти фігуру.

**Міфологічна**
15. **Затемнювач** — кнопка з cooldown; створює по вибраній діагоналі бар'єр на 1 хід суперника — цю лінію не можна перетинати.

### 5.3 Тури (15 карток, 4/4/4/2/1)

**Звичайні**
1. **Класична тура**
2. **Снайпер-тура** — не б'є впритул по вертикалі/горизонталі, ціль мінімум за 2 клітинки; після далекого взяття може пройти ще 1 клітинку далі по тій самій лінії.
3. **Десантна тура** — першим ходом перестрибує одну фігуру по вертикалі/горизонталі, стаючи одразу за нею; після цього пропускає наступний хід.
4. **Маневрова тура** — ходить і б'є по вертикалі, горизонталі й діагоналі, максимум на 4 клітинки за хід.

**Рідкісні**
5. **Стрибуча тура** — постійно перестрибує через одну фігуру на своїй лінії, стаючи на першу вільну клітинку за нею.
6. **Рикошетна тура** — доходячи до краю дошки, в межах того ж ходу відрикошетить на 1 клітинку вліво чи вправо.
7. **Тура-ілюзіоніст** — після ходу лишає приховану копію на стартовій клітинці (див. §4.6).
8. **Тунельна тура** — ходить як тура, а ще може піти на 1 клітинку по діагоналі, лише на вільну, без взяття («Тихий крок»; змінено, див. engine-decisions.md).

**Епічні**
9. **Кутова тура** — якщо перша частина ходу до 3 клітинок по вертикалі/горизонталі, може раз повернути на 90° і пройти до 2 клітинок після повороту; якщо поворот не використано — ходить без обмеження в 4 клітинки.
10. **Таранна тура** — раз за гру проходить крізь одну ворожу фігуру на своїй лінії, не чіпаючи її, і бере фігуру за нею (між ними можуть бути вільні клітинки); короля так брати не можна, шах через прохідну фігуру не оголошується.
11. **Витіснювач** — постійно: може стати на клітинку своєї фігури на лінії ходу (шлях вільний); ця фігура відштовхується на 1 клітинку далі в тому ж напрямку, тура займає її місце. Якщо клітинка за фігурою зайнята чи це край дошки — хід нелегальний. Короля відштовхувати не можна. Хід нелегальний, якщо після нього власний король під шахом.
12. **Смертник** — постійно: коли туру б'є будь-яка фігура, крім тури й ферзя, ця фігура теж гине.

**Легендарні**
13. **Замкова тура** — раз за гру, замість ходу, телепортується з будь-якої точки дошки на будь-яку **вільну** клітинку з 8 навколо свого короля (без взяття); може закрити короля від шаху по лінії; не рятує від шаху конем чи пішаком.
14. **Фортечна тура** — раз за гру, коли її б'є будь-яка фігура, крім тури й ферзя, не гине: фігура-переможець лишається на клітинці тури, а тура відходить на 1 клітинку (пріоритет назад, якщо зайнято — вбік; якщо немає вільної клітинки — гине як звичайно). Після відходу тура пропускає наступний хід.

**Міфологічна**
15. **Землетрус** — кнопка, cooldown 8 своїх ходів; обираєш вертикаль/горизонталь без короля на ній, усі фігури на ній зсуваються на 1 клітинку в обраний бік, крайня переходить на протилежний край.

### 5.4 Коні (15 карток, 4/4/4/2/1)

**Звичайні**
1. **Класичний кінь**
2. **Верблюд** — стрибає "3+1" замість "2+1", перестрибує фігури; завжди на клітинках одного кольору.
3. **Гінець** — лише першим ходом стрибає рівно на 2 клітинки прямо вперед (перестрибуючи фігури, може бити на клітинці приземлення); далі ходить як класичний кінь.
4. **Діагональник** — лише першим ходом стрибає рівно на 2 клітинки по діагоналі в будь-який бік (перестрибуючи фігури, може бити на приземленні); далі ходить як класичний кінь.

**Рідкісні**
5. **Кінь-ілюзіоніст** — після ходу лишає приховану копію на стартовій клітинці (див. §4.6).
6. **Оруженосець** — ходить як кінь, плюс може пройти 1 клітинку по вертикалі/горизонталі без взяття.
7. **Центровий кінь** — поки стоїть у центрі дошки (клітинки c3–f6), може стрибати і як звичайний кінь, і "3+1"; поза центром — звичайний кінь.
8. **Побратим** — поки поруч (на 8 сусідніх клітинках) стоїть інший свій кінь, може стрибати ще й "3+1".

**Епічні**
9. **Стінобіг** — постійно: якщо стрибок приземлив коня на клітинку **краю дошки**, у тому ж ході може пройти ще 1-2 клітинки вздовж цього краю в будь-який бік, без взяття (шлях має бути вільний); з кутової клітинки — вздовж будь-якого з двох країв.
10. **Скакун** — першим ходом у партії робить два стрибки поспіль (перший без взяття, другий може бити); після цього пропускає наступний хід.
11. **Трамплін** — постійно: не блокує ходи власних слонів, тур і ферзя (вони проходять крізь нього як крізь порожню клітинку); ворожі фігури проходити не можуть.
12. **Ротатор** — замість стрибка міняється місцями зі своїм пішаком на будь-якій із 8 сусідніх клітинок (без взяття); пішак не може опинитись на 1-му чи 8-му ряду; той самий кінь не може зробити обмін двічі поспіль.

**Легендарні**
13. **Берсерк** — після взяття може одразу стрибнути ще раз, якщо цей стрибок теж бере фігуру; після ланцюга пропускає наступний хід.
14. **Вершник** — кінь може стрибнути на клітинку свого пішака: пішак не гине, а "сідає" на коня (поки на коні — не ходить і не б'є). Коли коня б'ють: кінь не гине, гине пішак-пасажир, фігура-переможець лишається на клітинці коня, власник обирає вільну клітинку для відстрибу (будь-яка, куди кінь міг би стрибнути без взяття); після відстрибу кінь пропускає наступний хід. Якщо вільної клітинки немає — гинуть обоє. Щоб знову скористатись ефектом, потрібно заново посадити на коня живого пішака.

**Міфологічна**
15. **Міраж** — кнопка, cooldown 5 своїх ходів; коня цим ходом стрибає без взяття, а на всіх інших вільних клітинках, куди він міг би стрибнути, з'являються приховані ілюзії (мінімум 2 вільні клітинки потрібно, інакше кнопка неактивна); див. §4.6, тривалість — 3 ходи суперника або до наступного ходу справжнього коня.

### 5.5 Ферзь (5 карток, по 1 на рідкість)

1. **Класичний ферзь** (Зв) — стандартний хід.
2. **Рикошетна** (Рд) — ходить як звичайний ферзь; доходячи до краю дошки, в межах того ж ходу відрикошетить: по діагоналі — на нову діагональ, по прямій — на 1 клітинку вліво/вправо від краю.
3. **Амазонка** (Еп) — ходить як ферзь, але максимум на 5 клітинок за хід; додатково може ходити як кінь, але без взяття.
4. **Левітаційна** (Лг) — cooldown 5 своїх ходів (без ліміту "раз за гру"); та сама механіка платформи, що й у Левітаційного слона.
5. **Безсмертна** (Мф) — кнопка, cooldown 8 своїх ходів, не витрачає хід. Ефект діє 1 хід суперника. Якщо в цей час ферзя б'ють — не гине, фігура-переможець лишається на місці, ферзь переходить на стартову клітинку (або найближчу вільну на 1-му ряду) **без дебафів**. Якщо не били — нічого не відбувається. Суперник не бачить, чи натиснута кнопка (прихований стан).

### 5.6 Король (5 карток, по 1 на рідкість)

1. **Класичний король** (Зв) — стандартний хід, з рокіровкою.
2. **Мандрівник** (Рд) — постійно: ходить по вертикалі/горизонталі на 1 або 2 клітинки; по діагоналі не ходить. Для ходу на 2 клітинки проміжна клітинка має бути вільна й не під боєм. Рокіровка стандартна.
3. **Обмінник** (Еп) — раз за гру, замість ходу, якщо король на своєму 1-му ряду, міняється місцями з будь-якою своєю фігурою на цьому ряду (навіть через інші фігури); після обміну король не під шахом; втрачає право рокіровки.
4. **Барикада** (Лг) — раз за гру, автоматично: коли королю ставлять мат по лінії (вертикаль/горизонталь/діагональ), на клітинці впритул до короля на цій лінії з'являється свій пішак, перекриваючи шах (мату немає, партія триває); працює й на 1-му ряду. Не працює проти коня, пішака, подвійного шаху, і коли фігура, що б'є, вже впритул до короля.
5. **Підказка** (Мф) — кнопка, cooldown 5 своїх ходів, не витрачає хід. Показує власнику найкращий хід у поточній позиції за оцінкою власного рушія (не стандартний шаховий рушій — він не знає модифікованих правил). Рахується на позиції, яку бачить власник (без чужих ілюзій). Суперник нічого не бачить.

## 6. Рушій правил — вимоги до реалізації

- Архітектура "картка → функція генерації ходів": для кожної `moveModifierId` окрема функція `generateMoves(piece, board, matchState)`, яка повертає список легальних цільових клітинок і супутні ефекти (взяття, спецдії). Це дозволяє додавати нові картки, не чіпаючи ядро.
- Ядро: стандартна шахова логіка (порожня дошка, лінії атаки, перевірка шаху/мату/пату, рокіровка) — спільна база, яку картки або використовують як є, або перевизначають.
- Для MVP: реалізувати повністю всі звичайні й рідкісні картки (32 картки — прості геометричні модифікації), потім епічні, легендарні, міфологічні. Картки без реалізації тимчасово підміняються класичним ходом відповідної фігури (fallback), щоб гра не ламалась, — позначити такі в коді коментарем `// TODO: <назва картки>`.
- Обов'язково: перевірка "після ходу власний король не під шахом" застосовується до **будь-якого** результату дії картки, включно зі спецефектами (штовхання, обмін місцями, телепорт).
- Прихований стан (`hiddenState`) віддається клієнту лише для сторони, якій він належить; серверна (або локальна ізольована) логіка не повинна передавати чужі ілюзії чи прапорці кнопок у відповіді іншому гравцю/боту.

## 7. Бот (MVP)

- **Рівень:** простий, не повинен грати ідеально — оцінка через матеріал + мобільність.
- **Оцінка позиції:** сума ваг фігур бота мінус сума ваг фігур суперника; вага фігури залежить від типу руху (базова цінність класичної фігури + невеликий бонус за додаткові можливості картки, підбирається вручну для балансу). Плюс невеликий бонус за кількість легальних ходів (мобільність).
- **Пошук ходу:** мінімакс глибиною 2 (свій хід + відповідь суперника) з альфа-бета відсіканням, працює поверх того самого генератора легальних ходів `generateMoves`, що й для гравця — бот не має власного окремого набору правил.
- **Використання активних здібностей (кнопки):** бот активує кнопку, якщо це покращує оцінку позиції на глибині пошуку; якщо реалізація ефекту ще не готова (fallback), бот кнопку не використовує.
- **Складність:** параметризована глибина пошуку (1-3), щоб пізніше додати рівні складності без переписування бота.

## 8. Технічний стек (пропозиція, не жорстка вимога)

- Фронтенд: будь-який SPA-фреймворк або чистий HTML/CSS/JS для дошки й конструктора колоди.
- Бекенд/рушій: логіку рушія правил варто писати окремим модулем/пакетом без прив'язки до UI, щоб той самий код рахував ходи гравця, ходи бота і майбутню підказку короля.
- Стан матчу для MVP можна тримати повністю на клієнті (гра проти бота, без мережі); структура `MatchState` з §3 лишається сумісною, якщо пізніше матч переїде на сервер для PvP.

## 9. Критерії приймання MVP

1. Конструктор колоди не дає зберегти колоду, що порушує будь-яке обмеження з §2.2.
2. Партія проти бота від початкової позиції до мату/пату/нічиєї проходить без помилок рушія на колодах, зібраних лише з класичних + звичайних + рідкісних карток.
3. Хоча б одна картка кожного типу ефекту (постійний, раз за гру, кнопка з cooldown, автоматичний) працює коректно, включно з перевіркою шаху після її застосування.
4. Каталог карток (§5) відображає всі 69 записів з фільтрами за фігурою й рідкістю.
5. Бот робить легальний хід кожного разу і не зависає (пошук глибини 2 має вкладатися в прийнятний час, наприклад до 2 секунд на хід).

## 10. Відкриті питання

- Числові ваги фігур для оцінки бота — підбираються тестуванням, стартові значення в ТЗ не фіксуються.
- Порядок реалізації карток за межами звичайних/рідкісних (§6) — за пріоритетом розробника чи дедлайном.
- Система випадіння й економіка карток — окремий ТЗ (уже описаний як промпт для схеми БД), у цей скелет не входить.
