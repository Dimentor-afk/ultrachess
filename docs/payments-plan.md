# Осколки за гроші — план на потім

Зараз у грі **немає жодних платежів**: осколки лише ігрові (повторки карток). Код оплати був написаний,
протестований і прибраний, щоб не тримати в продукті те, що ще не можна законно запустити.

## Повернути код

Уся реалізація — в одному коміті `e93d7fd` («Shards for money…»), прибрана комітом `ed44690`.
Повернути:

```bash
git revert ed44690   # або: git cherry-pick e93d7fd
```

Що там було (і з'явиться знову):

- **Набори осколків** за гривні (120 💎 — 39 ₴, 650 — 199 ₴, 1400 — 399 ₴, 3000 — 799 ₴).
- **Журнал покупок** (таблиця `purchases`): запис до оплати; зарахування рівно один раз — статус покупки й
  баланс осколків змінюються в одній транзакції; інша сума не зараховується; повернення коштів забирає
  осколки.
- **monobank (Plata by mono):** рахунок `invoice/create`, повідомлення про оплату з перевіркою підпису
  ECDSA, запит статусу, якщо повідомлення загубилось (`server/monobank.ts`, змінна `MONO_TOKEN`).
- **Тестова оплата** (`PAYMENTS=test` і в демо): екран «Оплатити / Відхилити» замість банку.
- **Шанси випадіння** під кожним паком у магазині (паки за куплені осколки — це лутбокси).
- **Публічна оферта й політика конфіденційності** (`#/terms`, `#/privacy`) — шаблони з місцями для даних ФОП.
- Журнал покупок в адмін-панелі; 9 тестів (`src/economy/__tests__/payments.test.ts`).

## Що потрібно, щоб запустити

1. **Юридично продавати.** Варіанти:
   - **ФОП** (через Дію, 3 група — 5 % від доходу + щомісячний ЄСВ) і еквайринг monobank — код уже під це;
   - **посередник, що продає від свого імені** (Google Play Billing, Xsolla, Paddle, Lemon Squeezy) — треба
     перевірити, чи працюють із фізособами з України; потрібен ще один клас `PaymentProvider`;
   - **донати без нагород** (банка monobank, Ko-fi) — не продаж, але дохід треба декларувати.
   Деталі — з бухгалтером.
2. Дані продавця в оферті (`src/ui/LegalPage.tsx`, `SELLER`), фіскальні чеки (ПРРО), якщо потрібні.
3. Тестовий токен monobank → перевірка на сервері → бойовий токен
   (`fly secrets set MONO_TOKEN=… PUBLIC_URL=https://ultrachess.fly.dev`).

## Коли повертатись

Коли гравців буде сотні й стане зрозуміло, що вони готові платити. До того — тестова оплата не потрібна,
а економіка гри працює на осколках з повторок.
