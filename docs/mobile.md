# Мобільний додаток (iOS)

Додаток у `ios/` — нативна оболонка [Capacitor](https://capacitorjs.com/) навколо живого сайту:
він відкриває https://ultrachess.app (`capacitor.config.ts`), тож акаунти, партії й сервер ті самі,
що й у браузері, а зміни на сайті доходять до додатка без нової збірки. Перезбирати треба лише тоді,
коли міняється нативне: іконка, заставка, плагіни, назва.

Що в ньому: іконка й заставка з іконки сайту, лише портретна орієнтація на iPhone, світлий текст
у рядку стану (`@capacitor/status-bar`), заставка без спінера (`@capacitor/splash-screen`).

## Запустити на своєму iPhone через Xcode

Потрібні Mac із свіжим Xcode з App Store (відкрити раз, щоб він доставив компоненти) і iPhone з
iOS 15 або новішою. Платний акаунт розробника не потрібен: вистачить безкоштовного Apple ID.

1. У терміналі:
   ```sh
   cd ~/ultrachess
   git pull
   npm install
   npm run build
   npx cap sync ios
   npx cap open ios
   ```
   Відкриється Xcode з проєктом `App`. Першого разу він хвилину-дві качає пакети Capacitor (Swift
   Package Manager, CocoaPods не потрібен).
2. Ліворуч клацни синю іконку **App** → таргет **App** → вкладка **Signing & Capabilities** →
   **Team** → **Add an Account…**, увійди своїм Apple ID і вибери **(Personal Team)**.
   Якщо Xcode скаже, що `app.ultrachess` уже зайнятий, зміни **Bundle Identifier** на свій,
   наприклад `app.ultrachess.dima`.
3. Підключи iPhone кабелем, розблокуй і натисни «Довіряти цьому комп'ютеру». На iPhone:
   **Параметри → Приватність і безпека → Режим розробника → увімкнути** (телефон перезавантажиться).
4. У Xcode вгорі вибери свій iPhone і натисни ▶ (`Cmd+R`).
5. Перший запуск iPhone заблокує («Ненадійний розробник»): **Параметри → Загальні →
   VPN і керування пристроями** → твій Apple ID → **Довіряти**. Потім відкрий додаток ще раз.

З безкоштовним Apple ID додаток працює 7 днів, потім просто натисни ▶ у Xcode ще раз.

## Що далі

- **Сповіщення «твій хід»:** плагін `@capacitor/push-notifications` і Apple Push (потрібен платний
  акаунт розробника, $99 на рік), на сервері — відправка при ході суперника.
- **App Store:** платний акаунт, і вирішити з покупками. Apple вимагає свої покупки в додатку для
  уламків і паків (правило 3.1.1), тож або сховати в додатку покупки за гроші (зараз їх і так бачать
  лише адміни, `GameService.paymentsAdminOnly`), або додати Apple In-App Purchase як третього
  провайдера оплати. Ще Apple не любить «просто сайт в обгортці» (правило 4.2): перед публікацією
  варто додати нативне — сповіщення, вібрацію на ходах.
- **Android:** `npx cap add android` і збірка в Android Studio; ті самі питання з покупками в Google Play.
